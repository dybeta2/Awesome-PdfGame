## Introduction

Awesome-PdfGame is a repository dedicated to collecting innovative games that run within PDF files. These games leverage JavaScript support in modern PDF engines, transforming static documents into interactive gaming platforms.

## How to Play

PDF games work best in modern browsers with:
- **PDFium** - Chrome, Edge, Brave
- **PDF.js** - Firefox and others

No special software required beyond a modern web browser.

## FAQ

- **How do PDF games work?** They use JavaScript in modern PDF engines with form fields and annotations for graphics and input handling.
- **Which browsers work best?** Chromium-based browsers with PDFium engine offer optimal compatibility.
- **Are these games safe?** Yes, all games run in the sandboxed environment of your PDF viewer.
- **Why play games in PDF?** They showcase PDF technology's versatility while providing unique gaming experiences.

## Technical Basics

PDF games utilize:
1. JavaScript execution in PDF engines
2. Form field manipulation for UI elements
3. Annotation layers for graphics
4. Hidden text fields for input capture
5. Dynamic updating for game loops
